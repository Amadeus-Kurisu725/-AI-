## 这是什么

**教程**（[制作全流程与其他游戏适配指南.md](制作全流程与其他游戏适配指南.md)，23 节）记录了一个真实项目从第一段录像配音走到完整播放器的全过程，也包括大量返工：

- 台词明明在网页里，解析器却漏掉；
- 音频文件明明存在，里面读的却是另一句；
- 几十项检查全部通过，实际观看仍然错位；
- 一段音频本来能用，却因为识别模型没听清而反复重做。

比「装好一个模型，点生成」更值得写下来的，是这些。

**工具包**（[制作工具包/](制作工具包/README.md)）是把这些经验重新整理的**可移植教学实现**，把台本检查、配置冻结、逐句生成、盲回读、审核登记和章节打包串成一条可运行、可检验的流程。

> ⚠️ 它是**教学子集**，不是原生产工程的全量源码。网页采集、游戏专用资源解析、完整人机容差规则、多路 GPU 调度、字幕截图、进程文字读取和手机界面**都不包含在本包中**。

## 30 秒跑起来

只需要 **Python 3.11 或以上** —— **不下载模型、不调用在线服务、不需要独立显卡**：

```console
cd 制作工具包
python -m voicekit --config config.example.json demo
```

Windows 也可以直接双击 `制作工具包\运行离线示例.cmd`。

> 默认演示**只生成明确标记的提示音**，用来验证数据、任务与导出流程。
> **提示音不能当成真实配音**，演示结果也不代表真实声音审核通过。

要生成真实语音，需要你另外准备本地 GPT-SoVITS 服务、可用的参考录音和本地识别模型 —— 详见[工具包说明](制作工具包/README.md)。
