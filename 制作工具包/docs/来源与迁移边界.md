# 来源与迁移边界

本工具包由《战双帕弥什》配音工程的实际经验整理成独立教学实现，版本 0.1.0。它没有携带作者本机的任务清单、历史采纳名单、音频库、账户配置或运行状态。

## 来自原工程的机制

| 原工程关注点 | 本包体现 |
|---|---|
| 正文、朗读派生和来源分离 | JSONL 的对应字段与冻结清单 |
| 生成身份不能随审核规则变化失效 | 声音／TTS绑定与审核裁决分离 |
| ASR 差异不是确定错音 | `supported` 或 `needs_review` 建议，正式采纳另行执行 |
| 文件名不证明音频身份 | WAV检查、哈希与绑定回验 |
| 旧候选和失败证据不能随意覆盖 | 按绑定身份保存工作记录 |
| 分支不能按文件顺序硬串 | 显式选择、路径、汇合与结构检查 |
| 模拟测试不能冒充真实生产 | demo候选、模拟证据、演示包隔离 |

## 为了可移植而明确缩小的范围

没有直接复制原生产控制器及其全部审核政策。原控制器依赖具体文本总表、四类参考声音、模型目录、历史回执、章节范围与生产锁；把个人盘符换成相对路径仍不足以成为通用工具。

本版使用单进程逐句调用 GPT-SoVITS API、可选本地识别与显式人工采纳，覆盖一条可理解、可检验的完整链路。它不宣称具备原工程的大规模吞吐、跨章调度、同音与语义政策、多路内容位置互补、声音微调训练或全套恢复能力。

真实服务的模型身份由操作者记录。HTTP的成功音频响应不能证明服务端一定运行所声明的权重，所以切模型后应更新配置并重新准备；测试对此不做虚假保证。

## 现有源码和工具入口

- [Windows 播放器](https://github.com/abc85713344/pgr-voice-desktop)：界面、输入、播放和战双专用文字跟随。移植其他游戏时观察层需要重做。
- [Android 播放器](https://github.com/abc85713344/pgr-voice-android)：导入、悬浮、按需 OCR 与移动端操作。
- [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)：合成与模型训练；本包通过其 API 使用。
- [openai-whisper](https://github.com/openai/whisper)：本地完整回读后端之一，不是在线 OpenAI API。
- [SenseVoice](https://github.com/QwenAudio/SenseVoice) 与 [FunASR](https://github.com/modelscope/FunASR)：另一种本地回读方式。
- [pgr-assets](https://github.com/huaxu-app/pgr-assets) 与 [UnityPy](https://github.com/K0lb3/UnityPy)：原工程离线资源整理所用工具，不是所有游戏的通用文字提取器。

上游项目的许可和依赖以其自身版本为准。本包的非商业许可证不能覆盖或替代它们，也没有授予游戏原声和剧情的再分发权。

## 其他游戏需要自行适配的内容

文本入口和来源快照；章节结构；角色与声音映射；变量和玩家名；分支、循环与条件；已有原声；当前句定位；屏幕字幕区域与特效；游戏推进输入；不同客户端版本。先用手动模式验证一段小剧情，再逐步增加自动化。

## 不要一起上传的文件

本地配置、私有音频、模型权重、访问凭据、任务日志、真实游戏台词、工作与输出目录。随包的 `.gitignore` 是辅助措施，发布前仍要检查实际提交清单。
