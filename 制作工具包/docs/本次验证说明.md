# 本次验证说明

验证日期：2026-10-07。工具包版本：0.1.0。

在 Windows、Python 3.11.9 环境执行 `python -B -m unittest discover -s tests -v`，34 项测试通过。

| 范围 | 已验证的行为 |
|---|---|
| 台本与配置 | 来源、稳定 ID、大小写冲突、缺失目标、不可达节点、循环、错误汇合、路径越界及参考变更检查 |
| 候选与证据 | 音频绑定、波形损坏与静音拒绝、独立模型证据、不覆盖已有证据、正式采纳及导出门槛 |
| 审核 | 否定词、数字、重复正文和编号符号差异不会因为宽泛相似度自动通过 |
| 本地 API 适配 | 使用临时模拟 HTTP 服务，验证请求正文、参考绑定、受限参数、有效结果复用与失败后停止 |
| ASR 适配 | 使用模拟模型对象，验证本地模型身份、盲回读参数、原始文字保留和证据复用 |
| CSV 导入 | UTF-8 BOM、引号与换行、来源与原文保留、分支信息拒绝、输出原子新增及不覆盖 |
| 用户命令入口 | 在包含中文的临时路径中完整执行演示；再次运行复用结果；阶段失败返回非零并停止导出 |

完整演示生成了 7 条提示音和 7 份明确标记的模拟记录；0 条正式采纳，导出状态为 `DEMO_NOT_VOICE`。两条剧情分支与汇合结构保留。相同文本的不同剧情位置继续保留各自 ID；提示音内容相同，所以按内容哈希导出时可以引用同一音频文件。

这些验证没有调用真实 GPT-SoVITS、Whisper 或 SenseVoice 模型，没有使用真实游戏台词和角色参考音频，也没有操作原有生产任务。

真实模型质量、使用者的 CUDA/依赖环境、目标播放器运行和游戏内路线仍需要独立验证。导出回执中的 `player_runtime_verified` 保持为 `false`，不能把结构检查说成实际播放器验收。

生成目录与测试缓存不随源码分发。拿到工具包后可按 README 重跑演示和测试。
